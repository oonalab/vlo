    Class InProcessTracker

    Counts handlers this process still owes a result for. One tracker is shared by every in-process transport a host builds, because Host.drain has to tell "the dispatcher moved nothing" apart from "the dispatcher moved nothing yet: a handler is running and its result will schedule the next task".
