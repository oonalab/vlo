    @vlo/sdk/host — everything that touches durable state or the network.

    The authoring surface (@vlo/sdk) has no dependency on any of this: a workflow compiles and unit-tests without a journal, a kernel or a port.

    • handler(options: CreateHostOptions): { GET: FetchHandler; POST: FetchHandler }

      Next route file: export const { GET, POST } = handler({ … }). The host is created on the first request and shared by every request after, so a serverless function pays for the kernel load once per instance. Pair it with dispatcher: { mode: "manual" } and a cron on POST /v1/timers/tick.

      Parameters

      • options: CreateHostOptions

      Returns { GET: FetchHandler; POST: FetchHandler }

      Example

      // app/api/vlo/[[...path]]/route.ts
      import { handler } from "@vlo/sdk/host";

      export const { GET, POST } = handler({
        journal: process.env.DATABASE_URL ?? "sqlite://./.vlo/dev.db",
        workflows: [pipeline],
        activities: [render],
        basePath: "/api/vlo",
        dispatcher: { mode: "manual" },
      });
