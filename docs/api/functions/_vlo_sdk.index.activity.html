      Defines an activity: a named unit of work a worker implements and a reducer requests with cmd.task.

      The content hash covers name, both schemas (as JSON Schema, projected by projectSchema so annotations such as description and default are hash-neutral) and the resolved retry policy, so changing any of them yields a new schemaRef; queue, leaseMs and timeoutMs are operational and hash-neutral. Runs pin the schemaRef per event, so old and new versions coexist.

      import { z } from "zod";
      import { activity } from "@vlo/sdk";

        retry: { maxAttempts: 3 },

        timeoutMs: 30_000,
