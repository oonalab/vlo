    Function defineWorkflow

    • defineWorkflow<S, I>(name: string, def: WorkflowDef<S, I>): Workflow<S, I>

      Defines a workflow: a named, pure reducer over the run's events.

      def is either a hand-written WorkflowDef or the output of sequence. Handlers must not read a clock, generate randomness or do I/O; time and randomness arrive on the event. State must be JSON-serialisable: it is stringified after every reduction. A handler that throws fails the run (see WorkflowFailure); so does an event whose handler is not registered, or a handler returning anything but [state, Command[]].

      Example

      import { cmd, defineWorkflow } from "@vlo/sdk";
      import { work } from "./activities.ts";

      export default defineWorkflow("uppercase", {
        init: (input: { item: string }) => ({ item: input.item }),
        on: {
          started: (s) => [s, [cmd.task(work, { item: s.item })]],
          task_done: (s, e) => [s, [cmd.complete(e.output ?? null)]],
        },
      });
