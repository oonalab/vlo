    Function sequence

    • sequence(
          steps: readonly SeqStep[],
          options?: SequenceOptions,
      ): WorkflowDef<SeqState, Json>

      Compiles an ordered list of phases into a WorkflowDef for defineWorkflow.

      Phases run one after another: step, fanOut, fanOutRuns, waitFor and sleep. Outputs go to results keyed by activity or workflow name and signal payloads to signals keyed by signal name, so two phases on the same target share a key. After the last phase the run completes with results, or with options.output(state). state.usage always holds the run's banked usage as of the last event. Events that do not belong to the current phase are ignored: state unchanged, no commands.

      Parameters

      • steps: readonly SeqStep[]
      • options: SequenceOptions = {}

      Returns WorkflowDef<SeqState, Json>

      Example

      import {
        defineWorkflow, fanOut, fanOutResultsOf, resultOf, sequence, signalOf, step, waitFor,
      } from "@vlo/sdk";
      import { approve, finish, plan, work } from "./activities.ts";

      export default defineWorkflow("example", sequence([
        step(plan),
        fanOut(work, (s) => resultOf(s, plan).items.map((item) => ({ item })), { concurrency: 2 }),
        waitFor(approve),
        step(finish, (s) => ({
          uppers: fanOutResultsOf(s, work).map((o) => o.upper),
          approvedBy: signalOf(s, approve).by,
        })),
      ], { output: (s) => ({ report: resultOf(s, finish).report, tokens: s.usage?.tokens ?? 0 }) }));
