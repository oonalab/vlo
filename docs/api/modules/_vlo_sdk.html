    @vlo/sdk

    The TypeScript SDK and host for Vlo, an event-sourced durable execution engine. A workflow is a pure reducer (state, event) → (state, commands); the Rust kernel (bundled as wasm) folds events, and your Postgres or a SQLite file is both the journal and the task queue.

    pnpm add @vlo/sdk zod          # Node ≥ 22.5

    import { activity, cmd, defineWorkflow, sequence, step } from "@vlo/sdk";
    import { z } from "zod";

    const greet = activity("greet", { input: z.object({ name: z.string() }), output: z.string() });

    export default defineWorkflow("hello", sequence([step(greet, (input) => input)]));
