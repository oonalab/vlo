    The command constructors a reducer returns to the engine. Each builds a plain Command; nothing runs until the host applies the reduction. task, timer, spawn and awaitSignal open a step, emit records a side effect, complete and continueAsNew close the run and must come last.

    Type Declaration

    • awaitHuman: <T>(definition: SignalDef<T>, options: AwaitHumanOptions) => Command[]

      awaitSignal with a deadline + emit("human", …); returns a Command[].

    • awaitSignal: <T>(definition: SignalDef<T>, options?: AwaitSignalOptions) => Command

      Parks the run until the named signal is delivered.

    • complete: (output: Json) => Command

      Closes the run as completed. Must be last.

    • continueAsNew: (input: Json) => Command

      Closes the run as continued with a fresh start input. Must be last.

    • emit: (channel: string, data: Json) => Command

      Publishes on a side channel; never journaled.

    • spawn: (
          workflow: string | { name: string },
          input: Json,
          options?: SpawnOptions,
      ) => Command

      Starts a child run; its result arrives as child_done.

    • task: <I, O>(target: Activity<I, O>, input: I, options?: TaskOptions) => Command

      Runs an activity once, with retries. Throws ActivityInputError on bad input.

    • timer: (options: TimerOptions) => Command

      Fires a timer event after ms or at atMs.

    Example

    import { cmd, defineWorkflow } from "@vlo/sdk";
    import { approve, work } from "./activities.ts";

    export default defineWorkflow("review", {
      init: (input: { item: string }) => ({ item: input.item, upper: null as string | null }),
      on: {
        started: (s) => [s, [cmd.task(work, { item: s.item })]],
        task_done: (s, e) => [
          { ...s, upper: (e.output as { upper: string }).upper },
          cmd.awaitHuman(approve, { id: "approval", timeoutMs: 86_400_000 }),
        ],
        signal: (s) => [s, [cmd.complete({ upper: s.upper })]],
        timer: (s) => [s, [cmd.complete(null)]],
      },
    });
