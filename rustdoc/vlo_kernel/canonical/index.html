Canonical JSON: parse, then re-serialize compact with object keys sorted.

serde_json::Map is a BTreeMap here (the preserve_order feature is off), so a parsed value re-serializes with sorted keys and no whitespace. NaN / Infinity are rejected by the parser and cannot exist inside a Value, so a canonical form is always valid JSON.

Numbers round-trip exactly within i64 / u64; larger integers become f64 and canonicalize to their shortest round-trip form. Canonicalization is idempotent: canonicalize(canonicalize(x)) == canonicalize(x).
