The closed set of kernel error codes.

Constants§

ALREADY_TERMINAL
The event is for an attempt the step has already moved past (a stale duplicate).
BAD_SEQ
started arrived on a run whose last_seq is not 0.
COMMANDS_AFTER_COMPLETION
A command follows complete / continue_as_new in the same reduction.
DUPLICATE_STEP_ID
A command names a step id that is already open.
ILLEGAL_TRANSITION
The step edge is not in the state machine, the step’s kind differs from the event’s, the event is for a future attempt, a retry skips an attempt, a signal lands on a step not awaiting one, or started arrives on a run that is not created.
INVALID_COMMAND
A command is malformed: empty activity, workflow, signal name, channel or explicit id, or a timer with neither fire_at_ms nor fire_in_ms.
INVALID_EVENT
The envelope fails a field check (empty id, bad random, both payload forms, bad payload_ref prefix, unroutable kind/status), belongs to another run, omits kernel_state, still carries an unresolved payload_ref, has a bad delay_ms, or is lifecycle-only but was sent to reduce_step. Also plan_retry with a bad random.
MALFORMED_JSON
An export input, an inline payload, a reducer state or a kernel output is not valid JSON.
MULTIPLE_COMPLETIONS
A reduction issues complete / continue_as_new more than once.
PAYLOAD_TOO_LARGE
An inline payload exceeds INLINE_LIMIT_BYTES.
RUN_CLOSED
The run is already closed (completed, failed, cancelled or continued); no further events are accepted.
UNKNOWN_STEP
The event names a step that is not open: never opened, or already pruned as terminal.
