The Vlo kernel: a pure, event-sourced state machine (see docs/workflows.md for the reducer contract and docs/kernel-protocol.md for the wire protocol).

Zero I/O, zero clock, zero randomness of its own. Everything it needs arrives on the event (ts_ms, random) or in the run’s persisted state, and everything it decides leaves as a declarative write-set the host applies atomically. That is what lets the same logic run on wasm in Node today and natively in a Durable Object later.

Errors are values: no input can make the kernel panic, which matters because the wasm profile builds with panic = "abort".
