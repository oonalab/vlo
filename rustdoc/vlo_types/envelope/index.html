Module envelope

The event envelope: kinds, statuses, causes, usage, and the journaled event shape.

The kernel routes on the header fields alone and never parses payload (see docs/kernel-protocol.md).

Structs§

Envelope
A journaled event: EventInput plus the kernel-assigned sequence number and the state hash after folding it (so a re-fold can pinpoint the divergent seq).
EventInput
An event as the host submits it, before the kernel assigns seq and state_hash.
Usage
Resource usage stamped on events and summed into KernelState. Integers only, because KernelState is hashed.

Enums§

Cause
Failure taxonomy. Retry policy is keyed on this, never on application error text.
Kind
The five event kinds. Projects cannot add kinds (see docs/kernel-protocol.md).
Status
The seven step statuses (see docs/kernel-protocol.md).
