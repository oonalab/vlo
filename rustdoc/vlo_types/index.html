Wire types for the Vlo kernel protocol (see docs/kernel-protocol.md).

Everything that crosses the wasm boundary or lands in a journal is defined here, once, with serde for the wire and schemars for the generated JSON Schema that the TypeScript SDK types are derived from.

Rules:

  • No floats in anything that is hashed (KernelState, Usage). Money is micro-USD.
  • Time is milliseconds since the Unix epoch (*_ms), never a date type.
  • JSON that must survive byte-exact (user state, payloads) is carried as String at the storage edge and as serde_json::Value inside the kernel.
